## Where the plan did not match the code, and what I did
1. **Line counts moved**: `app.py` was 773 at `aebff3a` (plan: 766). After the extraction 735, after the slots 739 (≤ 760, pinned).
2. **"Important, held at night, ring by day" needs `DAYTIME_RING_KINDS`.** `NotifySettings.ring_for` defaults to `"urgent"`, under which an important kind is delivered *silently* by day. Only `DAYTIME_RING_KINDS` gives "rings in waking hours, held in quiet hours" whatever that setting, so the three book kinds are in it (`tests/test_r51_seams.py`'s pin of the set now includes them).
3. **Alerts card**: `console-alerts.js` `KINDS` lacks R4's important `vitals_critical` and `health_fault`, so by the brief's rule the book kinds are not added either (pinned in `test_r6_seams.py`). Their switches still work through `PUT /v1/notify/settings`.
4. **`wire_r6` runs before the gateway exists.** Right after `wire_r4`, `app.state.permissions` and `app.state.gateway` are not built yet (`_wire_gateway` comes later). The `audit` passed is the chain the gateway is built on. I1: read permissions per request (`request.app.state.permissions`, as `api/vault.py` does) or build those parts after `_wire_gateway`.
5. **D11 vs the audit chain**: the chain lives in `jarvis.tools.audit`, which D11 forbids inside `jarvis.buildbook`, so `ports.BookAudit` is the structural view (I1 passes the real chain).
6. **`.gitignore`**: a bare `_book/` would also ignore `tests/fixtures/book/_book/`; the entry is `/src/jarvis/buildbook/_book/` (pinned with `git check-ignore`).
7. **The desktop dock already overflowed.** With 19 tabs it ran 82 px past each edge of a 1440 px window (Chat cut off left, Construct right); the R5.1 gate missed it (it audits panels, and Playwright could still click Construct's 2 visible pixels). The 20th tab (Book) made Media and Construct unreachable (`scripts/ui_snapshots.py` failed on them). Fix, desktop only (`min-width: 900px`): the dock keeps every tab at its usual size and look, stays inside the window and scrolls sideways (`overflow-x:auto`, tabs `flex:none`); a mouse wheel over it scrolls it and an opened panel's tab scrolls into view. **Owner/I1 decision**: keep this, or move the least-used tabs (Construct, Media) behind More on desktops narrower than the full dock (~1712 px).
8. **`console-permissions.js` threw on a page without its section** (`null.addEventListener` on `book.html`): it now returns after defining `JarvisPasskey` there (control run: without the guard the show page logs a pageerror).
9. **FastAPI 0.162 includes routers lazily** (`app.routes` holds `_IncludedRouter`s): the contract test reads the two routers' `APIRoute`s and proves "exactly these methods" with 405 probes through the app.
10. **`no-store` everywhere**: enforced once by `BookNoStore` (pure ASGI, installed by `install_r6_routes`), so the 401 from `require_auth`, a CSRF 403 and a 405 carry it too.
11. **Unspecified shapes I chose**: `release.json` `skipped` = an int count (the list is `THIRD_PARTY.json` in the zip); `bk_<16 hex>`, `br_<12 hex>`, `bf_<12 hex>`; `book_talk_questions` 1–50; the 503 detail "The build book isn't available on this server."
12. **The owner's closing**: D13 gives owner variants only for the 2nd and 3rd lines; `CLOSING["owner"]` = `credit, sealed_owner, thanks_owner` (the credit line is shared). Confirm at I1.
13. **Evals**: `evals/run_all_mock.py` gates `r6_book` now; at I0 every suite is "not built yet" and the run passes (a vacuous pass by design). **I1 must add `--require-all`** once A–C are merged.
14. **Not done at I0 (plan's I1)**: `r6_tick_jobs` into `_tick_jobs` and R5.1's watchdog list (`check_job_names`), `r6_privacy_sources` into `personal.privacy_sources`, persona p5.2 (R5.1 D12's p5.1 is unchanged), `api/book_lock.ShowLockMiddleware` in `install_show_lock`.
