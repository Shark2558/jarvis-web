"Hey Jarvis" wake-word models: licence and attribution

Files

Source
  openWakeWord v0.5.1 release assets by David Scripka
  https://github.com/dscripka/openWakeWord (releases/tag/v0.5.1)
  The embedding model is openWakeWord's re-implementation of Google's speech_embedding model
