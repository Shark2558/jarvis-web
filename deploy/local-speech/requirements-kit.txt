# deploy/local-speech/requirements-kit.txt -- R5.2 laptop speech kit: the only packages it installs,
# pinned and hash-checked (Windows, 64-bit, Python 3.12). install-kit.ps1 installs them into the
# kit's private environment with --require-hashes --only-binary=:all: (wheels only: nothing is
# compiled on the laptop). Resolved for win_amd64 / CPython 3.12 on 27 Nov 2026; every hash is the
# SHA-256 PyPI publishes for that wheel, and the whole set was downloaded once with
# --require-hashes for that platform (which also proves no dependency is missing).
# Licences are PyPI's own (licence expression or classifier); none is GPL. tqdm is MPL-2.0 AND MIT
# (file-level, used unmodified); typing-extensions is PSF-2.0. PyAV's wheel bundles FFmpeg and LAME
# (LGPL), loaded unmodified, as the cloud image's OpenCV does.
#
# Not here, on purpose (see README.md "What this kit leaves out"):
#   kokoro-onnx (MIT) needs phonemizer (GPL-3.0-or-later) and espeakng-loader (no licence stated;
#   it bundles espeak-ng, GPL-3.0); piper-tts 1.3+ is GPL-3.0-or-later; PyTorch / transformers /
#   parler-tts for the Indian-language engines. Their engine slots say "not installed".
#   NVIDIA's CUDA 12 / cuDNN 9 libraries (NVIDIA's own licence) are not pip-installed: the kit uses
#   the graphics card only when they are already on the laptop, else the CPU.
